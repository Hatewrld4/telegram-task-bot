# Telegram Task Manager Bot

Simple Telegram bot for saving and managing tasks using interactive Inline buttons.

## Features
- Save tasks from chat
- Interactive Inline buttons to mark tasks as completed
- SQLite database storage
- Simple command system

## Commands
/start - start bot  
/tasks - show active tasks list  

## Tech Stack
- Python
- python-telegram-bot
- SQLite3
- python-dotenv

## How to run
1. Install dependencies:
   ```bash
   pip install python-telegram-bot python-dotenv
